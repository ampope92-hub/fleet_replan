There is a README beside them explaining the columns. The dispatch side is written in Go so this has to be too; `/app/payroll` is a module with a stub in `/app/payroll/main.go`, no dependencies, and the box is offline with nothing on it past the standard library.

Fill in the module so that `cd /app/payroll && go build -o payroll . && ./payroll` reads the three files and writes `/app/out/payroll.json`.
